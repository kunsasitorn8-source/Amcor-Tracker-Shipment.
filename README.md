# วิธีติดตั้งระบบ Shipment Tracker (เวอร์ชันปรับปรุง)

ระบบนี้ใช้ **Google Sheets** เป็นฐานข้อมูล และ **Google Apps Script** เป็นเว็บแอปสำหรับให้ Siam Tin และ Amcor กรอกข้อมูลร่วมกัน โดย Amcor ไม่ต้อง Login เข้า Google Account

## สิ่งที่แก้ไข/เพิ่มจากเวอร์ชันก่อนหน้า

1. **ผู้กรอกข้อมูล (Recorded By)** — ทุกแถวมีช่องระบุว่าใครเป็นคนกรอก เลือกได้จาก dropdown "Siam Tin" หรือ "Amcor" ทั้งในหน้าเว็บและในตัวชีตเอง
2. **ช่องวันที่และ Week เป็น Dropdown**
   - ช่องที่เป็นวันที่ (เช่น ETD, ETA, ATD, ATA, Booking date, Loading date ฯลฯ) — ในตัว Google Sheet จะมี Data Validation แบบปฏิทิน (คลิกที่เซลล์แล้วเลือกวันที่ได้เลย) และในหน้าเว็บใช้ช่องเลือกวันที่ของเบราว์เซอร์อยู่แล้ว
   - ช่องที่เป็น Week (เช่น ETD Required week, Loading Week, ATD week, ATA Week) — เปลี่ยนเป็น dropdown ให้เลือก "Week 01" ถึง "Week 53" ทั้งในชีตและในหน้าเว็บ
3. **แยกเป็น 3 ชีตตามสายเรือ** โครงสร้างคอลัมน์เหมือนกันทุกชีต (เหมือนตารางตัวอย่างในไฟล์ PDF ที่แนบมา — คอลัมน์ไหนของ Siam Tin/Amcor ก็ยังเหมือนเดิม):
   - `Sheba - Maersk`
   - `Sheba - Evergreen` ⚠️ **เป็นชื่อตัวอย่าง** — ถ้าสายเรือที่ 2 ชื่ออื่น แก้ได้ที่ไฟล์ `Code.gs` บรรทัดเดียว (ตัวแปร `LINES` บนสุดของไฟล์) แล้ว deploy ใหม่
   - `Sheba - OOCL`
4. **ชีตสรุปยอด (`Summary`)** — คำนวณอัตโนมัติทุกครั้งที่มีการเพิ่ม/แก้ไขข้อมูลจากทั้ง 3 สายเรือ แสดง PO Quantity, ยอด Actual Qty Loaded แยกตามสายเรือ, ยอดรวม และยอดคงเหลือที่ยังไม่ได้ส่ง (Remaining to Ship) ต่อ PO — ไม่ต้องกดปุ่มใดๆ เพิ่ม แต่ถ้าอยากรีเฟรชเองก็มีเมนู **Shipment Tracker → รีเฟรชสรุปยอด (Summary)** ในหน้า Google Sheet

> **ไม่ต้องใช้ไฟล์ Excel Template แล้ว** — เวอร์ชันนี้ Apps Script จะสร้างชีตทั้ง 4 ชีต (3 สายเรือ + Summary) พร้อมหัวคอลัมน์และ Data Validation ให้อัตโนมัติในขั้นตอนติดตั้ง ไม่ต้อง import ไฟล์ xlsx เอง

## ขั้นตอนที่ 1: สร้าง Google Sheet เปล่า

1. ไปที่ [sheets.google.com](https://sheets.google.com) → สร้างสเปรดชีตใหม่ (เปล่าๆ ก็ได้)

## ขั้นตอนที่ 2: สร้าง Apps Script Project

1. ในไฟล์ Google Sheet ไปที่เมนู **Extensions → Apps Script**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ `Code.gs` ที่แนบมาแทน
3. สร้างไฟล์ HTML ใหม่ 1 ไฟล์ (คลิก `+` → HTML) ตั้งชื่อว่า **`Index`** (ต้องตรงเป๊ะ ห้ามมีนามสกุล .html ต่อท้ายตอนตั้งชื่อ) แล้ววางโค้ดจากไฟล์ `Index.html` ที่แนบมา
4. กด **Save** (ไอคอนแผ่นดิสก์) ทั้งโปรเจกต์
5. ถ้าต้องการเปลี่ยนชื่อสายเรือที่ 2 (ปัจจุบันตั้งไว้ว่า `Sheba - Evergreen`) ให้แก้ที่ตัวแปร `LINES` บรรทัดบนสุดของ `Code.gs` ก่อน แล้วค่อย Save

## ขั้นตอนที่ 3: สร้างชีตทั้งหมดครั้งแรก

1. กลับไปที่หน้า Google Sheet แล้ว **รีเฟรชหน้าเว็บ (F5)** — จะเห็นเมนูใหม่ชื่อ **"Shipment Tracker"** ปรากฏบนแถบเมนู
2. คลิก **Shipment Tracker → ตั้งค่า/สร้างชีตทั้งหมด (ครั้งแรก)**
3. ครั้งแรกที่รัน Google จะขอ permission — กด **Continue/Advanced → Go to (โปรเจกต์) → Allow** (เป็นสคริปต์ของคุณเอง ปลอดภัย)
4. ระบบจะสร้างชีต `Sheba - Maersk`, `Sheba - Evergreen`, `Sheba - OOCL`, `Summary` ให้ครบพร้อมหัวคอลัมน์และ dropdown ต่างๆ

## ขั้นตอนที่ 4: Deploy เป็น Web App

1. คลิก **Deploy → New deployment**
2. เลือกประเภท (ไอคอนเฟือง) → **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (บัญชีของคุณ)
   - **Who has access:** **Anyone** (สำคัญมาก — ต้องเลือก Anyone เพื่อให้ Amcor เข้าลิงก์ได้โดยไม่ต้อง Login)
4. กด **Deploy** → อนุญาต permission ตามที่ระบบขอ
5. จะได้ลิงก์ Web App เช่น `https://script.google.com/macros/s/xxxxx/exec`

## ขั้นตอนที่ 5: แจกลิงก์

- ส่งลิงก์เดียวกัน `https://script.google.com/macros/s/xxxxx/exec` ให้ทั้ง Amcor และทีม Siam Tin
- ในหน้าเว็บ แต่ละฝ่ายเลือก **สายเรือ** จาก dropdown บนสุดก่อน แล้วเลือกแท็บของตัวเอง ("Siam Tin" หรือ "Amcor") เพื่อกรอกข้อมูลฝั่งตัวเอง พร้อมเลือก **ผู้กรอกข้อมูล** ให้ตรงกับตัวเอง

> ทุกครั้งที่แก้โค้ดใน Apps Script ต้องกด **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → New version → Deploy** ลิงก์เดิมจะใช้โค้ดใหม่ได้เลย ไม่ต้องส่งลิงก์ใหม่ให้ Amcor

## ฟีเจอร์ที่มีให้

- Siam Tin สร้าง PO ใหม่ (เลือกสายเรือที่จะบันทึกด้วย) และแก้ไขข้อมูลฝั่งตัวเอง (PO info + ติดตามเรือช่วง Rotterdam→Songkhla)
- Amcor เลือก PO จาก dropdown ของแต่ละสายเรือ แล้วอัปเดตข้อมูล Booking/Loading/กำหนดการเรือ — เห็นและแก้ได้เฉพาะคอลัมน์ของตัวเอง
- ทุกแถวมีช่อง **Recorded By** ระบุผู้กรอกข้อมูลล่าสุด
- ช่องวันที่/week เป็น dropdown ทั้งในชีตและหน้าเว็บ
- ระบบคำนวณ **สถานะรวม** (New PO → Booked → Loaded → In Transit → Arrived) ให้อัตโนมัติจากข้อมูลที่กรอก แสดงในหน้าเว็บและใช้ในอีเมลแจ้งเตือน
- ชีต **Summary** รวมยอด PO Quantity / Actual Qty Loaded แยกตามสายเรือ + ยอดรวม + ยอดคงเหลือ อัตโนมัติทุกครั้งที่มีการบันทึกข้อมูล

## เปิดแจ้งเตือนอีเมลรายสัปดาห์ (ทางเลือก)

ในไฟล์ `Code.gs` มีฟังก์ชัน `sendWeeklyReminder()` พร้อมใช้ (จะดึงรายการ PO ที่ยังไม่ถึง Songkhla จากทั้ง 3 สายเรือมารวมในอีเมลเดียว):

1. แก้อีเมลใน `AMCOR_EMAIL` และ `SIAMTIN_EMAIL` ให้เป็นอีเมลจริง
2. ในหน้า Apps Script ไปที่เมนู **Triggers** (ไอคอนนาฬิกาด้านซ้าย) → **Add Trigger**
3. เลือกฟังก์ชัน `sendWeeklyReminder` → Event source: **Time-driven** → **Week timer** → เลือกวันจันทร์ ช่วงเช้า
4. ระบบจะส่งอีเมลสรุป PO ที่ยังไม่ถึงปลายทาง พร้อมลิงก์กรอกข้อมูล ให้ทั้งสองฝ่ายทุกสัปดาห์

## ข้อควรระวัง

- Amcor เข้าผ่านลิงก์แบบไม่ Login ดังนั้น **ทุกคนที่มีลิงก์นี้แก้ไขข้อมูลได้** — ควรส่งลิงก์เฉพาะผู้เกี่ยวข้อง และพิจารณาเปลี่ยนเป็นแบบ Login ในอนาคตหากข้อมูลละเอียดอ่อนขึ้น
- ฟอร์มปัจจุบันยึด **PO No. เป็นตัวระบุไม่ซ้ำกันภายในสายเรือเดียวกัน** ห้ามมี PO No. ซ้ำกันสองแถวในชีตเดียวกัน (ระบบจะเตือนถ้าซ้ำตอนสร้าง PO ใหม่) — แต่ PO No. เดียวกันสามารถใช้ได้กับคนละสายเรือ (เช่น แยกส่งเป็น 2 shipment คนละเรือ) ซึ่งชีต Summary จะรวมยอดให้อัตโนมัติ
- **PO No.** แก้ไขไม่ได้หลังสร้างแล้ว (เพื่อป้องกันข้อมูลไม่ตรงกับชีต Summary) แต่ **PO Date** แก้ไขได้ภายหลังจากฝั่ง Siam Tin
